# Applied Agentic AI for Modern Data Engineering

## TCS iON Course Assignments

This repository contains 10 assignments completed throughout the **Applied Agentic AI for Modern Data Engineering** course offered by TCS iON.

The repository showcases practical implementations, hands-on exercises, and learning outcomes related to modern data engineering, data integration, workflow automation, and Artificial Intelligence.

## 📚 Course Overview

The course focuses on developing practical knowledge of modern data engineering concepts and AI-powered data workflows.

### Technologies Covered

- Python
- n8n – Workflow Automation
- Airbyte – Data Integration
- Databricks SQL
- AWS Glue – ETL
- Apache Spark
- Data Pipelines
- Generative AI
- OpenAI API
- Google Gemini API
